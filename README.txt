DIE KNOBELZOCKER – CLUB EDITION 1.3.1 – PWA

START
1. ZIP-Datei entpacken.
2. index.html per Doppelklick öffnen.
3. Die Ordner css, js und assets müssen neben index.html bleiben.

Die Daten werden lokal im verwendeten Browser gespeichert.

PROJEKTSTRUKTUR
index.html
css/styles.css
js/app.js
assets/dice.png

- Fortschrittsbalken bis zum spätesten Beginn der letzten Runde
- Warnstufen für Schlussphase und letzte Runde

NEU IN VERSION 1.3 – PWA
- Installierbar auf iPad, iPhone, Android, Mac und Windows
- Eigene App-Symbole
- Offline-Nutzung nach dem ersten Laden
- Vollbilddarstellung über den Home-Bildschirm

WICHTIG
Eine PWA muss über eine HTTPS-Webadresse oder localhost geöffnet werden.
Beim direkten Öffnen von index.html aus der Dateien-App funktionieren Installation
und Offline-Cache nicht vollständig.

IPAD
Safari öffnen → Webadresse aufrufen → Teilen → Zum Home-Bildschirm
