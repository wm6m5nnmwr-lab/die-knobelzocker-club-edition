# PWA veröffentlichen

Die PWA benötigt eine HTTPS-Webadresse.

## GitHub Pages
1. Neues Repository erstellen.
2. Den Inhalt dieses Projektordners hochladen.
3. Unter Einstellungen → Pages den Hauptbranch veröffentlichen.
4. Die angezeigte Webadresse in Safari öffnen.

## Cloudflare Pages
1. Neues Pages-Projekt erstellen.
2. Projektordner oder GitHub-Repository verbinden.
3. Kein Build-Befehl erforderlich.

## Installation auf dem iPad
Safari → Teilen → Zum Home-Bildschirm
